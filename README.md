# focora

> Simple. Intentional. Built for deep focus.

**Live Website:** [focora-timer.vercel.app](https://focora-timer.vercel.app/)

focora is a personal focus timer built for deep work sessions.
Built for myself, shared publicly.

---

## Features

### Focus Timer
- Pomodoro, Flow, and Deep Work modes
- Custom break durations per mode
- Session tracking and daily focus goals

### Zen Mode
- Full-screen distraction-free workspace
- Wallpapers and ambient backgrounds
- Ambient sounds and binaural audio

### Habit Tracking
- Create and track custom habits
- Visual heatmap showing last 6 months
- Streak tracking and completion history

### Tasks
- Organize tasks alongside focus sessions
- Session-linked task progress

### Stats & Analytics
- Session history with timestamps, mode, and ratings
- Scratchpad history logs
- Focus charts and consistency tracking

### Scratchpad
- Minimal notepad built into the app
- Clears daily, history saved automatically
- Never lose a thought mid-session

### Wallpapers
- Curated wallpaper collection
- Solid colors and custom backgrounds

### Local-First
- No account required
- No cloud dependency
- Export and import your data anytime

## Getting Started

### Prerequisites
- Node.js 18+

### Installation

```bash
git clone https://github.com/Himanshu478140/study-timer.git
cd study-timer
npm install
npm run dev
```

Open `http://localhost:5173`

### Production Build

```bash
npm run build
```
